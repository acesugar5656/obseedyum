# Obseedyum

Windows için ücretsiz, Türkçe Minecraft sunucu paneli. Kurulum yok: `Obseedyum.exe`'yi aç, sürümü seç, Başlat'a bas.

- Python ya da Java kurmana gerek yok (gereken Java'yı Eclipse Temurin'den kendisi indirir).
- PaperMC'nin bütün sürümleri; indirilen her dosya SHA-256 ile doğrulanır.
- Akıllı RAM: sunucu küçük başlar, boşalınca belleği geri verir.
- Plus: sunucu evdeki boştaki bilgisayarında çalışsın, sen kendi bilgisayarından yönet.

**İndir:** [Releases](../../releases/latest) sayfasından `Obseedyum.zip`.

"Windows bilgisayarınızı korudu" uyarısı çıkarsa: Ek bilgi → Yine de çalıştır (program henüz imzalı değil).

Obseedyum bağımsız bir projedir. Minecraft, Mojang AB'nin markasıdır; Obseedyum'un Mojang ya da Microsoft ile bağlantısı yoktur.
